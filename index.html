Instrucciones
Cómo participar
1

Registra tu nombre

Edita data/players.json y agrega tu nombre al array "participantes". Haz commit y push a GitHub.

Ver ejemplo de players.json 
{
  "participantes": [
    "tunombre",
    "otrojugador"
  ]
}
2

Crea tu archivo de apuestas

Crea data/bets/tunombre.json con tus marcadores para cada partido. Importante: Tu nombre debe ser el mismo que en data/players.json.

Ver ejemplo de tunombre.json 
[
  { "matchId": 1, "gL": 2, "gV": 1 },
  { "matchId": 2, "gL": 0, "gV": 0 },
  { "matchId": 3, "gL": 1, "gV": 2 }
]
3

Haz commit antes del partido

El historial de Git garantiza transparencia total. Nadie puede cambiar sus apuestas "en secreto" sin que quede registro.

4

Sigue las posiciones en tiempo real

El administrador actualiza data/results.json y el dashboard recalcula todo automáticamente en el navegador.

Ver ejemplo de results.json 
[
  {
    "id": 1,
    "local": "Argentina",
    "visita": "Brasil",
    "gL": 2,
    "gV": 1,
    "status": "finalizado",
    "fase": "Grupos",
    "grupo": "A",
    "tipo": "N"
  }
]
5

Plus

Crea data/bets/tunombre.plus.json con tus predicciones de largo plazo y hacé commit antes de que inicien los partidos:

  • convocatoriaColombia — los 26 jugadores de Colombia que creés que irán al Mundial. Se otorga 1 pt por cada acierto y es el puntaje base inicial.
  • posicionesGrupos — el orden final (1°→4°) de cada uno de los 12 grupos (A–L). Se otorgan 2 pts por cada posición acertada.
  • top4 — el campeón, subcampeón, 3er y 4to puesto del torneo (8 / 5 / 4 / 3 pts).
  • goOn — en cada partido de eliminatoria, el equipo que avanza (matchId del partido + nombre del equipo). 2 pts c/u.
Ver ejemplo de archivo .plus.json 
{
  "posicionesGrupos": {
    "A": ["Brasil", "Argentina", "Uruguay", "Chile"],
    "B": ["Francia", "España", ...]
  },
  "top4": {
    "campeon": "Brasil",
    "subcampeon": "Argentina",
    "tercero": "Francia",
    "cuarto": "España"
  },
  "goOn": [
    { "matchId": 49, "equipo": "Argentina" }
  ],
  "convocatoriaColombia": [
    "Jugador 1",
    "Jugador 2"
  ]
}
